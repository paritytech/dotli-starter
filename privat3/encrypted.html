About This Demo

This page was encrypted using the @bcts/envelope library, which provides selective per-recipient encryption. Each recipient receives a unique private key that grants them — and only them — access to the decrypted content.

The encrypted payload was stored on-chain via the Bulletin Chain's TransactionStorage pallet and is retrievable through any IPFS gateway using the content CID.

How It Works

1. The sender uploads a file and specifies recipient names.
2. A symmetric key encrypts the document content.
3. The symmetric key is then encrypted to each recipient's public key.
4. The sealed envelope is stored on the Bulletin Chain.
5. Recipients scan their QR code and enter the CID to decrypt.
